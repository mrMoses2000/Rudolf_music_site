# Info.md - Путеводитель по проекту

Этот файл объясняет, как устроен проект "Musikschule CMS Bielefeld", где что лежит и как оно работает. Это "карта местности" для новых разработчиков и для вас.

## 🏗️ Архитектура: "Как это работает?"

Твой сайт — это современное **Single Page Application (SPA)** на базе **React**.

1.  **React (Vite):** Это "движок" сайта. В отличие от старых сайтов, где каждая страница грузилась отдельно, здесь сайт загружается один раз, а потом переходы между страницами происходят мгновенно, без перезагрузки. Это дает плавность и скорость.
2.  **Tailwind CSS:** Это "стилист". Мы не пишем огромные CSS файлы. Мы пишем классы прямо в HTML (например, `text-gold` делает текст золотым). Это позволяет быстро менять дизайн.
3.  **Blocks System:** (Новое от Codex). Мы внедрили систему "Блоков" для текстовых страниц (JeKits, Impressum). Это значит, что текст страницы не "прибит гвоздями" в коде, а берется из файла данных (`content.js`). Легче править текст, не ломая верстку.
4.  **Docker + Nginx:** Это "упаковка и доставка".
    *   **Docker:** Упаковывает весь сайт в контейнер. Гарантирует, что сайт будет работать одинаково и на моем ноутбуке, и на твоем VPS.
    *   **Nginx:** Сервер, который стоит внутри контейнера и отдает файлы браузеру. Быстрый и надежный.

## 📂 Структура папок (Где что искать?)

### `/site/src/` — Сердце проекта
Здесь лежит весь исходный код.

- **`main.jsx`**: Входная дверь. Сюда первым делом попадает браузер.
- **`App.jsx`**: "Навигатор". Здесь прописаны все маршруты (`/contact`, `/about` и т.д.) и настроена анимация переходов.
- **`index.css`**: Глобальные стили (шрифты, сброс стилей).

### `/site/src/data/content.js` — 🧠 МОЗГ ПРОЕКТА
Самый важный файл. Здесь лежит ВЕСЬ текст и ВСЕ ссылки на картинки.
*   Хочешь поменять цену на пианино? -> Иди в `content.js`.
*   Хочешь сменить фото скрипки? -> Иди в `content.js`.
*   Нашел опечатку? -> Иди в `content.js`.

### `/site/src/components/` — Кубики LEGO
Повторяющиеся элементы.
- **`Layout.jsx`**: "Рамка" сайта. Содержит Шапку (Меню) и Подвал. Они одинаковые на всех страницах.
- **`Blocks.jsx`**: Универсальный "строитель" текста. Превращает данные из "мозга" в красивые параграфы и списки.

### `/site/src/pages/` — Страницы
- **`Home.jsx`**: Главная. Самая сложная по анимациям.
- **`InstrumentPage.jsx`**: Шаблон для инструментов. Используется ОДИН файл для всех (Скрипка, Гитара и т.д.), просто подставляются разные данные.
- **`Contact.jsx`**: Форма обратной связи.
- **`JeKits.jsx`, `Impressum.jsx`**: Новые страницы, используют систему `Blocks`.

### `/site/tailwind.config.js` — Палитра художника
Здесь мы смешиваем краски.
- Мы определили цвета: `gold` (золото), `ink` (чернила для текста), `paper` (бумага для фона). Это основа "светлого" редизайна.

## 🚀 Как запустить?

В корне проекта лежит скрипт `run.sh`.
```bash
./run.sh
```
Эта команда делает всё: собирает сайт, упаковывает в Docker и запускает.
