Глава 2: Память ядра и sk_buff

Linux не копирует пакеты. Это правило №1. Вместо этого мы передаем указатель на огромную структуру sk_buff.

2.1. Ассемблерная Реальность

VISUALIZATION: skb_push(16)

Как добавить заголовок к пакету, не двигая байты? Функция skb_push. 

void *skb_push(struct sk_buff *skb, unsigned int p_len) {
    skb->data -= p_len;
    skb->len  += p_len;
    return skb->data;
}

На уровне регистров процессора (x86-64) эта операция выглядит так:

ИСПОЛНЕНИЕ МАШИННОГО КОДА

  • MOV RAX, [RDI + 0xD0] — Процессор загружает текущее значение указателя data из памяти (по смещению 0xD0 от начала структуры) в регистр аккумулятора.
  • SUB RAX, RSI — Вычитает длину заголовка из адреса. Адрес сдвигается "влево" (в сторону младших адресов).
  • MOV [RDI + 0xD0], RAX — Сохраняет новый адрес обратно в память.
  • Теперь, когда код будет писать по skb->data, он будет писать в свободное пространство ПЕРЕД старыми данными. Стоимость: 3 такта.
