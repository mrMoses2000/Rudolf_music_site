Глава 1: Аппаратное Обеспечение и DMA

Сетевая карта (NIC) — это автономный компьютер. Она не ждет приказов CPU на каждый байт. Вместо этого они используют общую "почтовую ячейку" в оперативной памяти — Ring Buffer.

1.1. Молекулярный Уровень: Запись в Память

Что происходит на уровне транзисторов и шины, когда пакет прилетает в карту? Карта использует Ring Buffer (кольцевой буфер дескрипторов).

ALLOCATION: dma_alloc_coherent()

Драйвер не делает malloc(). Ему нужна физически непрерывная память, которую видит устройство. Он вызывает:

dma_alloc_coherent(dev, size, &dma_handle, GFP_KERNEL);
  • RDH (Head): Индекс, где hardware закончила писать. (Пишет карта, читает драйвер).
  • RDT (Tail): Индекс, где hardware может писать. (Пишет драйвер, читает карта).
  • Если RDH == RDT, буфер пуст (или полон, там хитрая арифметика).

STRUKT E1000_RX_DESC (Intel Driver)

NIC не пишет пакет абы куда. Она читает Дескриптор — структуру размером 16 байт, которая говорит карте, куда положить данные. 

struct e1000_rx_desc {
    /* 0x00 */ u64 buffer_addr; /* 64-bit Physical Address of SKB Data */
    /* 0x08 */ u16 length;      /* Length of data written */
    /* 0x0A */ u16 csum;        /* Checksum calculated by hardware */
    /* 0x0C */ u8  status;      /* Status bits (DD, EOP) */
    /* 0x0D */ u8  errors;      /* Error bits */
    /* 0x0E */ u16 special;     /* VLAN tag usually goes here */
};

ПРИЧИННО-СЛЕДСТВЕННАЯ СВЯЗЬ: DIRECT MEMORY ACCESS (DMA)

  1. Fetch: NIC считывает свой внутренний регистр RDT (Tail Index). Пусть он равен 5.
  2. Address Calculation: NIC вычисляет физический адрес дескриптора в RAM: $$Addr = Base + (5 \times 16)$$
  3. PCIe Read: NIC отправляет электрический сигнал по шине PCIe (TLP Read Request). Контроллер памяти (MMU) возвращает 16 байт дескриптора.
  4. Extraction: NIC извлекает из дескриптора поле buffer_addr (например, 0xFF1000).
  5. Write Packet: NIC начинает пересылать байты принятого пакета (Payload) прямиком по адресу 0xFF1000. CPU в этот момент может спать или считать числа Фибоначчи — он не задействован.
  6. Write Back: Закончив, NIC снова пишет в RAM (в дескриптор), заполняя поля length и выставляя бит статуса DD=1 (Descriptor Done). Это сигнал драйверу: "Я всё!"
