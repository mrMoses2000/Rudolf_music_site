# Rudolf Music Site (App)

Этот каталог содержит фронтенд (React + Vite). Полная документация — в корневом `README.md`.

## Быстрый старт
```bash
npm install
npm run dev
```

## Важно
- Контент правится в `src/data/content.js`.
- Изображения лежат в `public/images/`.
- Оптимизация изображений — через `SmartImage` и `srcSet`.
